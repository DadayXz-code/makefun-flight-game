Sky Courier is an original 2D canvas flight game: a little airmail pilot flying a red-and-white prop plane over rolling green valleys. Thread golden rings, land gently on three island runways, or outrun a storm to Skyport airfield — while watching fuel, altitude, speed and heading on the lit instruments. Keyboard and touch controls, procedural WebAudio engine and wind, title / pause / mission-complete screens, and a best score per mission saved in your browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, just static files.
